# Phase 1 & 2 Context

From StateExtractor (Phase 1/2):
- DecisionRecord captures individual agent decisions with timestamp, run_id, agent_name, decision, reasoning, confidence
- AgentEvent captures state transitions (from_state → to_state) for causal chain reconstruction
- Both models have timestamp fields for chronological ordering

From Research (03-RESEARCH.md):
- Trail aggregation by run_id groups all events from a single graph execution
- Causal chains use AgentEvent state_transition events to show which agent called which
- TrailNode represents decision points (agent decisions)
- TrailEdge represents causal links (state transitions)
</context>

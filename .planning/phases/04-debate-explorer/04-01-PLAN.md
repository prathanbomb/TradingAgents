# Plan 04-01: Build DebateParser to Extract and Structure Debate Arguments

## Goal

Create `DebateParser` that extracts structured debate data (bull/bear researcher arguments and risk analyst arguments) from the `DebateState` captured in `DecisionRecord`, enabling users to explore individual arguments by speaker rather than reading unstructured conversation history.

## Requirements Coverage

- **DEBATE-01**: Users can explore bull researcher arguments for each decision
- **DEBATE-02**: Users can explore bear researcher arguments for each decision
- **DEBATE-04**: Users can explore risk analyst debates (risk/safe/neutral perspectives)

## Overview

Phase 1 captured debate state in `DecisionRecord.debate_state` with structured fields (`bull_history`, `bear_history`, `judge_decision`, `count`), but these fields contain unstructured text with speaker prefixes ("Bull Analyst: argument text"). This plan creates a parser that extracts individual arguments by speaker, enabling structured access for downstream UI components.

### Task 2: Implement DebateParser with Speaker Identification

**Class to implement:**

```python
class DebateParser:
    """Parse debate state from DecisionRecord into structured debates.

    Extracts individual arguments from unstructured conversation history
    using speaker prefix patterns (e.g., "Bull Analyst: text").
    """

    def __init__(self, speaker_patterns: Optional[Dict[str, str]] = None):
        """Initialize parser with optional custom speaker patterns.

        Args:
            speaker_patterns: Optional mapping of debate_type to speaker names.
                Defaults to standard patterns if not provided.
        """

    def parse_investment_debate(
        self,
        debate_state: DebateState,
        run_id: str,
        ticker: str,
        trade_date: str
    ) -> Debate:
        """Parse bull/bear investment debate.

        Extracts arguments from bull_history and bear_history fields,
        identifies speaker prefixes ("Bull Analyst:", "Bear Analyst:"),
        and constructs a structured Debate object.

        Args:
            debate_state: InvestDebateState from DecisionRecord.debate_state
            run_id: Run identifier for linking to DecisionTrail
            ticker: Stock ticker symbol
            trade_date: Trade date in YYYY-MM-DD format

        Returns:
            Debate with bull and bear arguments + judgment
        """

    def parse_risk_debate(
        self,
        risk_debate_state: RiskDebateState,
        run_id: str,
        ticker: str,
        trade_date: str
    ) -> Debate:
        """Parse three-way risk debate (risky/safe/neutral perspectives).

        Extracts arguments from risky_history, safe_history, and neutral_history,
        identifies three speaker prefixes ("Risky Analyst:", "Safe Analyst:", "Neutral Analyst:"),
        and constructs a structured Debate object.

        Args:
            risk_debate_state: RiskDebateState from DecisionRecord.debate_state
            run_id: Run identifier for linking to DecisionTrail
            ticker: Stock ticker symbol
            trade_date: Trade date in YYYY-MM-DD format

        Returns:
            Debate with risky, safe, and neutral arguments + judgment
        """

    def _parse_speaker_arguments(
        self,
        history: str,
        speaker: str,
        debate_type: Literal["investment", "risk"]
    ) -> List[Argument]:
        """Parse individual arguments from speaker's history.

        Uses regex pattern to identify argument boundaries:
        Pattern: r"Speaker:\s*(.*?)(?=\n(?:Speaker:)|\Z)"

        Handles edge cases:
        - Multi-line arguments (re.DOTALL flag)
        - Colons in argument text (negative lookahead)
        - Empty or malformed history (returns empty list)

        Args:
            history: Speaker's conversation history
            speaker: Speaker name to filter by
            debate_type: Type of debate for argument_type classification

        Returns:
            List of Argument objects in chronological order
        """
```

**Implementation notes:**
- Use `re.escape()` on speaker names to handle special characters
- Apply `re.DOTALL` flag to capture multi-line arguments
- Validate argument count against `debate_state.count` (log warning if mismatch)
- Handle missing or empty `debate_state` fields gracefully (return empty Debate)
- Extract timestamps from agent history if available (optional, can be None)
- Classify `argument_type` heuristically based on content (data_driven if contains numbers, qualitative otherwise)

**Requirements:** DEBATE-01 (bull arguments), DEBATE-02 (bear arguments), DEBATE-04 (risk debates)

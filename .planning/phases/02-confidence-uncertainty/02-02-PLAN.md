```python
# Weighted average by historical accuracy
def weighted_aggregation(confidences: Dict[str, float], weights: Dict[str, float]) -> float:
    total_weight = sum(weights.values())
    return sum(c * w for c, w in zip(confidences.values(), weights.values())) / total_weight

# Bayesian with Beta prior
def bayesian_aggregation(confidences: Dict[str, float], prior_alpha: float = 1.0, prior_beta: float = 1.0) -> float:
    posterior_alpha = prior_alpha + sum(confidences.values())
    posterior_beta = prior_beta + sum(1.0 - c for c in confidences.values())
    return posterior_alpha / (posterior_alpha + posterior_beta)

# Minimum consensus (conservative)
def consensus_aggregation(confidences: Dict[str, float]) -> float:
    return min(confidences.values()) if confidences else 0.5
```

    1. **weighted_average(confidences: Dict[str, float], weights: Dict[str, float]) -> float**:
       - Accepts dict of {agent_name: confidence} and {agent_name: weight}
       - Validates that agent names match between dicts
       - Computes weighted average: sum(confidence * weight) / sum(weights)
       - Returns float between 0-1
       - Raises ValueError if weights empty or agent names mismatch

    2. **bayesian_aggregate(confidences: Dict[str, float], prior_alpha: float = 1.0, prior_beta: float = 1.0) -> float**:
       - Treats each confidence as evidence for Beta distribution
       - Computes posterior: alpha = prior_alpha + sum(confidences), beta = prior_beta + sum(1 - confidences)
       - Returns expected value: alpha / (alpha + beta)
       - Supports custom priors (default: uniform Beta(1,1))
       - Returns 0.5 if confidences empty (uninformed prior)

    3. **consensus_minimum(confidences: Dict[str, float]) -> float**:
       - Returns minimum confidence across all agents (conservative)
       - Returns 0.5 if confidences empty (neutral default)
       - Suitable for high-stakes decisions where uncertainty matters

    4. **ConfidenceAggregator class**:
       - __init__(method: Literal["weighted", "bayesian", "consensus"] = "bayesian", weights: Optional[Dict[str, float]] = None)
       - aggregate(confidences: Dict[str, float]) -> float - routes to selected method
       - _validate_inputs(confidences, weights) - validates agent name alignment
       - get_agent_weights() -> Dict[str, float] - returns default weights if not provided
         - Default weights (based on agent hierarchy):
           * analyst: 0.15
           * researcher: 0.20
           * manager: 0.25
           * trader: 0.20
           * risk_judge: 0.20
         - Sum to 1.0, customizable via constructor

    Add comprehensive docstrings, type hints, and error handling. Use numpy for numerical operations if needed.

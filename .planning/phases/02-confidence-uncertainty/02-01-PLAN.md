  <files>tradingagents/observability/confidence/scorer.py</files>
  <action>
    Create ConfidenceScorer class with three confidence estimation methods from 02-RESEARCH.md:

    1. **verbalized_confidence(text: str) -> Optional[float]**:
       - Regex patterns for: "(\d+)%\s*sure", "(\d+)%\s*confident", "confidence[:\s]+(\d+)%"
       - Case-insensitive matching
       - Returns float between 0-1 (percentage / 100)
       - None if no pattern found

    2. **ensemble_confidence(llm, prompt: str, num_samples: int = 3) -> float**:
       - Async function that samples LLM num_samples times
       - Uses sentence-transformers for semantic similarity (all-MiniLM-L6-v2 model)
       - Computes pairwise cosine similarity between embeddings
       - Returns average similarity as confidence score
       - NOTE: Mark as expensive operation, use only when verbalized fails
       - Handle sentence-transformers import error gracefully (return None if not installed)

    3. **token_confidence(llm_output) -> Optional[float]**:
       - Extracts logprobs from llm_output.llm_output if available
       - Computes average probability: np.exp(lp) for each logprob
       - Returns mean probability or None if logprobs unavailable
       - Works with LangChain message objects

    4. **ConfidenceScorer.score(agent_output: str, llm_output=None, llm=None, prompt: str = None) -> AgentConfidence**:
       - Tries methods in order: verbalized (fastest) -> token_probability (if available) -> ensemble (if llm provided)
       - Returns AgentConfidence with method and metadata
       - Falls back to 0.5 (neutral) if all methods fail

    Add proper error handling, logging, and type hints. Use numpy for numerical operations (already in project from scikit-learn dependency).

    DO NOT install sentence-transformers in this task - handle ImportError gracefully and log warning that ensemble confidence unavailable without package.
  </action>

# Roadmap: Trading Agents Observatory

## Overview

Build a transparency layer for the multi-agent LLM trading system by first establishing non-blocking data collection instrumentation, then adding confidence scoring to quantify certainty, followed by decision trail visualization to show reasoning flow, debate exploration to reveal adversarial analysis, and finally historical performance tracking to correlate decisions with outcomes.

## Phase Details

### Phase 1: Data Collection & Instrumentation

**Goal**: System captures all agent decision events asynchronously without blocking the trading pipeline, establishing the foundation for all observability features.

**Depends on**: Nothing (first phase)

**Requirements**: DATA-01, DATA-02, DATA-03, DATA-04, DATA-05

**Success Criteria** (what must be TRUE):
1. System captures decision events at each agent step without blocking the trading pipeline
2. Data collection is asynchronous and non-blocking to maintain analysis performance
3. Outcome tracking hooks are built into the data model from day one
4. System implements structured logging for all agent state transitions
5. LangGraph callback integration captures full decision context (reasoning, debates, confidence)

Plans:
- [x] 01-01-PLAN.md — Create DecisionRecord and AgentEvent Pydantic models with outcome tracking hooks (DATA-03, DATA-04)
- [x] 01-02-PLAN.md — Implement LanggraphCollector and StateExtractor using astream_events (DATA-01, DATA-05)
- [x] 01-03-PLAN.md — Build async data pipeline with producer-consumer queue and SQLite backend (DATA-01, DATA-02)
- [x] 01-04-PLAN.md — Integrate observability into TradingAgentsGraph with configuration (DATA-01, DATA-05)

### Phase 2: Confidence & Uncertainty

**Goal**: Each agent reports confidence scores that are aggregated into system-level confidence, with calibration tracking to assess reliability over time.

**Depends on**: Phase 1

**Requirements**: CONF-01, CONF-02, CONF-03, CONF-04

**Success Criteria** (what must be TRUE):
1. Each agent reports a confidence score with its output
2. System aggregates individual agent confidences into a system-level confidence score
3. Confidence calibration tracking records whether confidence levels match actual accuracy
4. Users can view confidence history to assess system reliability

**Plans**: 4 plans

Plans:
- [x] 02-01-PLAN.md — Implement confidence reporting with multiple estimation methods (verbalized, ensemble, token probability) (CONF-01)
- [x] 02-02-PLAN.md — Build confidence aggregation algorithms (weighted, Bayesian, consensus) for system-level scoring (CONF-02)
- [x] 02-03-PLAN.md — Create confidence calibration tracking with ECE calculation and SQLite storage (CONF-03)
- [x] 02-04-PLAN.md — Build confidence history query interface with trend analysis and calibration summary (CONF-04)

### Phase 3: Decision Trail

**Goal**: Users can view the complete timeline of decision flow from data input through analysis, debate, and final recommendation.

**Depends on**: Phase 1, Phase 2

**Requirements**: TRAIL-01, TRAIL-02, TRAIL-03, TRAIL-04

**Success Criteria** (what must be TRUE):
1. User can view a timeline of decision flow from data input to final recommendation
2. Timeline shows each agent's action and output in chronological order
3. User can filter and search through past decision trails
4. System displays the causal chain from data → analysis → debate → decision

**Plans**: 4 plans

Plans:

- [x] 03-02-PLAN.md — Build TrailBuilder to aggregate events by run_id and reconstruct causal chains (TRAIL-01, TRAIL-02, TRAIL-04)
- [x] 03-03-PLAN.md — Implement TrailQuery interface for filtering and searching decision trails (TRAIL-03)
- [x] 03-04-PLAN.md — Build TrailRenderer for text-based decision trail visualization with timeline and causal views (TRAIL-01, TRAIL-02, TRAIL-04)

### Phase 4: Debate Explorer

**Goal**: Users can explore agent arguments (bull/bear research, risk debates) with progressive disclosure from summary to detailed transcripts.

**Depends on**: Phase 1, Phase 3

**Requirements**: DEBATE-01, DEBATE-02, DEBATE-03, DEBATE-04, DEBATE-05, DEBATE-06

**Success Criteria** (what must be TRUE):
1. User can explore bull researcher arguments for each decision
2. User can explore bear researcher arguments for each decision
3. User can see how the research manager judged the debate
4. User can explore risk analyst debates (risk/safe/neutral perspectives)
5. System extracts and highlights key arguments rather than showing full transcripts
6. Progressive disclosure shows summary first, details on demand

### Phase 5: Historical Performance

**Goal**: System correlates past decisions with actual market outcomes, enabling users to assess agent-level and system-level performance over time.

**Depends on**: Phase 1, Phase 2

**Requirements**: PERF-01, PERF-02, PERF-03, PERF-04, PERF-05

**Success Criteria** (what must be TRUE):
1. System stores all decisions with full context for later retrieval
2. User can view past decisions and their outcomes
3. System correlates decisions with actual market outcomes after time delay
4. User can view agent-level performance attribution (which agents were right/wrong)
5. Performance metrics include confidence-weighted accuracy
